# FS25_Fresh compatibility mapping

`customDefaults.xml.example` is a loadable FS25_Fresh external overlay using
the installed v2 schema. Copy it to
`modSettings/FS25_Fresh/customDefaults.xml` on each FS25 installation. It is
read at game launch and does not modify FS25_Fresh or the savegame.

| Class | Fill types | Suggested treatment |
|---|---|---|
| Fresh | TOMATO, PEPPER, EGGPLANT, ASPARAGUS_WHITE, ASPARAGUS_GREEN, SPRING_ONION, CHILLI, GARLIC, GREENBEAN, PEA, SPINACH, ENOKI, OYSTER, BASIL, PARSLEY, ROSEMARY, SAGE, CHIVES, THYME, LEMONBALM | short shelf life; cooled |
| Dairy | MILK, GOATMILK, BUFFALOMILK, CREAM, GOAT_CREAM, RICOTTA, GOAT_RICOTTA, BUFFALO_RICOTTA, BUFFALOMOZZARELLA | short/medium; cooled |
| Sauces | PASSATA, SUGO_AL_POMODORO, ARRABBIATA, MARINARA, SUGO_AI_FUNGHI, PESTO, PESTO_ROSSO, PRESERVED_PEPPERS, GARLIC_IN_OIL, MUSHROOMS_IN_OIL | medium; cooled |
| Long-lived | SESAME_OIL, LAVENDER_OIL, MINT_OIL, DRIED_BASIL, DRIED_PARSLEY, DRIED_ROSEMARY, DRIED_SAGE, DRIED_THYME, DRIED_MINT, RED_WINE, WHITE_WINE | long; indoor |
| Meals | PASTA_AL_POMODORO, PASTA_ARRABBIATA, PASTA_AI_FUNGHI, PASTA_AL_PESTO, GNOCCHI_AL_POMODORO, RAVIOLI | perishable; cooled |
